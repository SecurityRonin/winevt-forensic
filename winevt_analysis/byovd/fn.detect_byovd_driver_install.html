Detect installation of a known-vulnerable driver service.

Matches Security EID 4697 and System EID 7045 (service installed) where ServiceName is in [BYOVD_DRIVER_NAMES]. QWCrypt uses the Zemana AntiMalware driver (zamguard64) to terminate EDR/AV at kernel level before deploying the encryptor (T1068).
