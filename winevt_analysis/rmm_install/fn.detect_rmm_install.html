Detect installation of a remote-monitoring/management (RMM) tool outside C:\Program Files\ or C:\Program Files (x86)\ (T1219 — Remote Access Software).

Threat actors drop AnyDesk, ScreenConnect, TeamViewer, Atera, etc. into %TEMP%, %APPDATA%, or C:\ProgramData\ to maintain interactive access while evading policy-based RMM blocklists. ~25/76 families use RMM tools for lateral movement or persistent interactive C2 alongside their encryptor.

Fires on Sysmon EID 11 (File Create) when TargetFilename basename is in RMM_BINARY_NAMES and the full path does NOT start with a safe install prefix.
