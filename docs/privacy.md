# Privacy Policy

*Last updated: 2026-06-15*

## Summary

winevt-forensic is a local Rust library and CLI. It does not collect, transmit, or store any personal data on remote servers.

## Data Access

winevt-forensic reads only the file bytes you pass to it. All processing happens in memory on your local machine. Nothing is uploaded anywhere.

## Telemetry

winevt-forensic has **no telemetry**. It makes no network requests of any kind.

## Open Source

winevt-forensic is open source (Apache-2.0). You can audit every line of code at [github.com/SecurityRonin/winevt-forensic](https://github.com/SecurityRonin/winevt-forensic).
