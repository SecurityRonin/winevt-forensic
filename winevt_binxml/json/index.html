Render a decoded BinXml ir tree to a serde_json::Value.

This is the general-purpose / debug projection (issen itself consumes the flat DecodedRecord instead). The shape follows the common omerbenamram-style convention: attributes become @name keys, character data becomes #text, a leaf element with only text becomes a bare string, and repeated same-named child elements become a JSON array.
