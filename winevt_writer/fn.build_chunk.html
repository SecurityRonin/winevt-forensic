pub fn build_chunk(records: &[WriteRecord], chunk_number: u64) -> [u8; 65536]
Expand description

Pack records into a 65536-byte ElfChnk block.

chunk_number is the 0-based index of this chunk in the file (used for the first_event_record_number / last_event_record_number fields which are sequence numbers within the log).

Records are written sequentially; any record that would overflow the records area is silently dropped (callers must split batches beforehand via split_into_chunks).
