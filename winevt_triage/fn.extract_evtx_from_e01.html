Expand description

Extract all *.evtx files from an E01 forensic image into out_dir.

Opens the image via [ewf::EwfReader], locates the NTFS partition via the MBR, traverses Windows/System32/winevt/Logs/, and writes each file to out_dir/<filename>.evtx.
