Struct ManifestDb

pub struct ManifestDb { /* private fields */ }
Expand description

Maps (normalized_provider_guid, event_id) to an ordered list of field names.

Field names correspond to positions in the BinXML substitution array; the EVTX parser emits them as Param1, Param2, … when no manifest is available at decode time. resolve_fields replaces those anonymous names with the actual names declared in the provider’s <template> element.

pub fn resolve_fields( &self, event_id: u32, provider_guid: &str, data: &mut HashMap<String, String>, )

Rename Param1, Param2, … keys in data to their declared field names.

Keys that are not ParamN (already named, or from a different format) are left untouched. If the provider/event combination is unknown, data is returned unchanged.
